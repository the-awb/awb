# Bundled score examples

These are complete canonical documents that the Score Studio **Demo score** action can open
without filesystem access.

`sonic-attunement-01.score.json` wraps the eleven-event manual projection from
`awbCollider/examples/score-projects/sonic-attunement-01/attunement-01.score.json` at awbCollider
`ca32ac7`. Its entries are the real fourteen-minute example used by the hosted and standalone
integration gates; only the required `awb.score/1` schema and descriptive metadata were added.

This is a pinned demo snapshot, not a second live score authority. If the source example changes,
update the provenance and explicitly review the bundled entries rather than silently syncing them.
