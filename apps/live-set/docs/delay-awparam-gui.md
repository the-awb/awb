# Delay module AWParam GUI — 8 October 2026

Implemented locally on `integration/bw-sc`. The eight rotary controls in each bound tape view use `AWParamKnob` from `apps/param/src/widgets.jsx`: Input, Dry, FX, Feedback and four directional head amounts. There is no second modulation knob bank in the live-set host. The same pedal/dictionary aliases address the same AWParams.

The tape module imports the shared GUI bundle and borrows metadata/observations from its attachment host. The host's existing parameter connection validates edits and supplies one active native control reader for the local server. It neither creates parameters from GUI state nor recreates modulation in JavaScript. The small attachment adapter checks the actual frame, loopback origin, session and allowed cell IDs. Closing or hiding a panel releases its subscriptions without retiring audio; owner loss disables parameter edits. These are GUI attachments to the existing module parameter owner, not another set of host controls.

`AWBDelayRack` already binds cell fields externally to the plain delay graph. Dry now has its `dryOf` alias; each head amount now has one AWParam (`h1Amount`…`h4Amount` aliases). Legacy head edits call that parameter's `setBase`, preserving its bus mapping and modulation. Cell feedback still multiplies each enabled directional return, without new gain normalization. No native DSP source/binary change, private DSP parameter system or new pedal assignment.

Central knob drag and arrow keys edit base; the outer ring edits signed depth. Hovering/focusing reveals the shared Sources button. Its popup exposes base/depth, overall curve and existing source controls. Green arcs and the compact percentage readouts use measured effective values. The waveform, time handles, timing row and slim transport retain their existing layout. Timing is still the existing AWParam-bound field edited through its current slider; this change covers rotary controls.
